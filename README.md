# PP_TP1_53401
**Plataforma de Gestión de Eventos Universitarios**

Esta solución digital centraliza la administración de la vida académica y extracurricular mediante tres módulos principales:

* **Estudiantes:** Registro centralizado e inscripción directa a congresos, jornadas y seminarios.
* **Eventos y Salas:** Creación y programación de eventos con control automatizado de aforos y asignación de espacios físicos.
* **Actividades:** Organización detallada de cronogramas, charlas y talleres específicos para cada propuesta.
